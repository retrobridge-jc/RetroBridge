# Changelog

## V1.1 - 8-Bit Edition

- redesigned the 480x320 frontend;
- added machine-specific accent palettes;
- added chunky bordered controls;
- added loading transitions;
- added history/archive views;
- retained diagnostics, maintenance, reboot, and shutdown;
- preserved all five known-good machine integrations;
- created and verified a whole-card recovery image.

## V1.0 - Five-System Release Candidate

- Apple-1 operational;
- TRS-80 BASIC experience operational;
- Apple II via EWM operational;
- IBM PC via DOSBox operational;
- C64 via VICE/open-roms operational;
- boot-to-RetroBridge;
- maintenance escape hatch;
- system status and power controls.

## V1.1 publication-model update
- Public release changed to an integration-platform model: no third-party emulator trees/binaries, proprietary ROMs, historical OS images, commercial games, or disk images are redistributed.
- Added `docs/THIRD_PARTY.md` with recommended upstream sources.
- Public Apple-1 integration now targets externally obtained EWM `builtin:apple1`.
- Added Apple-1 EWM launcher and updated component check.
- Added curated publication gallery, 3D-printable enclosure concept cover, BOM sourcing, and second-card recovery validation.
- Commodore 64 remains an intentional `ENTER COMPUTER` teaser in public imagery.
