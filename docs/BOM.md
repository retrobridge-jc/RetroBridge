# Bill of Materials

This BOM documents the known-good RetroBridge V1.1 reference appliance. Prices and availability change; model identity is more important than a specific price.

| Component | Reference build | Notes |
|---|---|---|
| Single-board computer | Raspberry Pi 5 Model B, 8 GB | Reference appliance hardware |
| Display/case kit | GeeekPi/52Pi 3.5-inch touchscreen case for Raspberry Pi 5 | Reference kit; 320x480-native TFT used in 480x320 landscape |
| Cooling | Official Raspberry Pi 5 Active Cooler | Used in the reference build |
| Storage | microSD card, approximately 32 GB or larger | A separate card was used for clean-build validation |
| Input | USB keyboard | Historical environments and maintenance |
| Network | Wi-Fi or Ethernet | Installation/maintenance |
| Power | Raspberry Pi 5-appropriate USB-C supply | Use a supply suitable for the Pi 5 and attached peripherals |

## Sourcing reference

Reference case/display model previously sourced as Amazon ASIN `B0D7VDWBBC`. Verify current listing details before purchasing.

## Optional printable enclosure

The project includes an optional period-inspired enclosure **concept**. It is not yet an engineering-validated STL/STEP design. Dimensions, ports, cooling, fasteners, and print tolerances must be validated before publishing printable CAD files.
