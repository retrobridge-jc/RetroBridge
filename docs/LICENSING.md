# Licensing and Redistribution Model

RetroBridge follows a deliberately conservative publication model:

> **RetroBridge is an integration platform, not a software archive.**

Included:

- RetroBridge frontend and startup logic;
- launcher scripts;
- configuration guidance;
- documentation and build instructions;
- original RetroBridge sample programs;
- project photographs and original/concept artwork.

Not included:

- EWM source/binaries;
- `trs80basic` source/binaries;
- DOSBox or VICE binaries;
- proprietary Apple, TRS-80, IBM/DOS, or Commodore ROM/software images;
- commercial games/applications;
- private full-card recovery images;
- SSH keys, Wi-Fi credentials, logs, or machine-specific secrets.

Each dependency remains governed by its own upstream license and terms. Linking to an upstream project is not a claim that RetroBridge owns, relicenses, or redistributes that project.

This document describes the project's publication approach and is not legal advice.
