## Enclosure status

The enclosure artwork is a **3D-printable enclosure concept/design target**, not yet an engineering-validated printable package.

Do not treat the pictured dimensions, port layout, fastener positions, thermal design, or assembly layout as final manufacturing data until CAD/STL files are created and physically validated.

The validated V1.1 reference appliance uses the off-the-shelf GeeekPi/52Pi 3.5-inch touchscreen enclosure.
