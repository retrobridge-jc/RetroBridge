# Third-Party Source Inventory

RetroBridge does not redistribute the third-party components below. This table records where builders should obtain them.

| Component | RetroBridge role | Bundled? | Recommended source |
|---|---|---:|---|
| Raspberry Pi OS / Debian | Host OS | No | Raspberry Pi / Debian |
| Python / Tkinter | Frontend runtime | No | OS packages |
| EWM | Apple-1 + Apple II | No | https://github.com/st3fan/ewm |
| `trs80basic` | TRS-80 | No | https://github.com/davidscan/trs80basic |
| DOSBox | IBM PC | No | https://www.dosbox.com/ or OS package |
| VICE | Commodore 64 | No | https://vice-emu.sourceforge.io/ or OS package |
| Debian `open-roms` | C64 replacement ROMs | No | Debian/Raspberry Pi OS package repository |
| MS-DOS / PC DOS | Optional IBM software | No | User-supplied lawful copy only |
| Commercial software/media | Optional | No | User-supplied lawful copy only |

See `docs/THIRD_PARTY.md` and `docs/LICENSING.md`.
